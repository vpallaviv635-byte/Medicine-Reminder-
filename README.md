# Medicine-Reminder-

The Medicine Reminder App helps users remember to take their medications on time. Users can add medicines, set reminder times, and receive notifications to ensure they never miss a dose.

Features

- Add new medicines
- Set daily reminder times
- View all scheduled medicines
- Edit or delete medicine records
- Notification alerts for medicine intake
- Simple and user-friendly interface

Tech stack:
- HTML
- CSS
- JavaScript

How to Use

1. Open the application.
2. Enter the medicine name.
3. Select the reminder time.
4. Click Add Medicine.
5. The medicine will be saved and displayed in the reminder list.
6. The app will notify you at the scheduled time.
